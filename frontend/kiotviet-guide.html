Hướng dẫn kết nối KiotViet

Kết nối gian hàng KiotViet với SAPI để đồng bộ sản phẩm, nhóm hàng, nhà cung cấp và hỗ trợ quá trình nhập hàng.

Kết nối API KiotViet là gì?

API KiotViet cho phép các hệ thống bên ngoài kết nối và trao đổi dữ liệu với gian hàng. SAPI sử dụng kết nối này để đồng bộ sản phẩm, nhóm hàng, nhà cung cấp và phục vụ quá trình nhập hàng.

Lưu ý bảo mật

Thông tin API chỉ nên cung cấp cho hệ thống đáng tin cậy. Không chia sẻ Client ID hoặc Mã bảo mật công khai.

1

Truy cập phần Thiết lập cửa hàng

Đăng nhập vào KiotViet bằng tài khoản quản trị. Từ màn hình quản lý, chọn:

Thiết lập → Cửa hàng

Vị trí ảnh minh họa bước 1: Thiết lập cửa hàng KiotViet
2

Mở mục Kết nối API

Trong menu bên trái, chọn:

Kết nối API → Chỉnh sửa

Vị trí ảnh minh họa bước 2: Màn hình Kết nối API KiotViet
3

Tạo thông tin API

KiotViet có thể yêu cầu xác thực trước khi tạo thông tin kết nối. Hãy thực hiện theo hướng dẫn trên màn hình:

  • Nhận và nhập mã xác thực.
  • Xác nhận điều khoản sử dụng API.
  • Tạo Mã bảo mật.
  • Lưu thông tin kết nối.
Vị trí ảnh minh họa bước 3: Tạo Mã bảo mật KiotViet
4

Lấy Client ID và Mã bảo mật

Sau khi hoàn tất thiết lập, KiotViet cung cấp hai thông tin dùng để xác thực:

Client ID

Định danh ứng dụng kết nối.

Mã bảo mật

Thông tin bí mật được sử dụng để xác thực kết nối.

Vị trí ảnh minh họa bước 4: Client ID và Mã bảo mật KiotViet

Kết nối với SAPI

Sau khi có thông tin API:

  1. Quay lại ứng dụng SAPI.
  2. Chọn Sửa thông tin, sau đó tìm phần KiotViet.
  3. Nhập Client ID và Mã bảo mật.
  4. Nhập tên gian hàng, ví dụ abc hoặc abc.kiotviet.vn.
  5. Nhấn Liên kết.

Sau khi xác thực thành công, SAPI sẽ hỏi bạn có muốn đồng bộ dữ liệu KiotViet ngay hay không.
