Hướng dẫn lấy Gemini API Key

Tạo API key trong Google AI Studio rồi lưu an toàn tại backend SAPI.

  1. Truy cập Google AI Studio.
    Mở trang API Keys chính thức ↗
  2. Đăng nhập tài khoản Google mà bạn muốn dùng để quản lý Gemini API.
  3. Trong Google AI Studio, mở khu vực Dashboard / API Keys.
  4. Chọn project phù hợp nếu đã có. Nếu chưa có, tạo project mới hoặc sử dụng project được AI Studio cung cấp.
  5. Chọn Create API key và xác nhận project cần liên kết.
  6. Copy API key vừa tạo. Không đăng key lên nơi công khai.
  7. Quay lại SAPI → Sửa thông tin → Gemini API, nhập key rồi chọn Kiểm tra và lưu API Key.

Lưu ý bảo mật và quota

  • Không chia sẻ API Key công khai và không commit key vào Git.
  • Không đưa API Key vào source code frontend.
  • Nếu key bị lộ, hãy vô hiệu hóa key cũ và tạo key mới trong Google AI Studio.
  • SAPI mã hóa, lưu và sử dụng API key ở backend; giao diện không hiển thị lại key đã lưu.
  • Google áp dụng quota/rate limit tùy tài khoản, project và tier. Khi hết quota, cần chờ hoặc kiểm tra hạn mức trong Google AI Studio.
